📝Введение

В задании 17 ЕГЭ по информатике дан файл с последовательностью целых чисел. Нужно проанализировать пары (или тройки) элементов, удовлетворяющих заданным условиям.

Типовая формулировка задачи выглядит так:

📋 Пример условия задачи:

Файл содержит последовательность целых чисел, не превышающих по модулю 10 000. Назовём парой два идущих подряд элемента последовательности. Определите количество таких пар, в которых запись ровно одного элемента заканчивается цифрой 6, а сумма квадратов элементов пары меньше, чем квадрат наименьшего из элементов последовательности, запись которых заканчивается цифрой 6.

В ответе запишите два числа: сначала количество найденных пар, затем максимальную сумму квадратов элементов этих пар.

Обратите внимание на два важных момента в условии:

  • Что считать парой: два идущих подряд элемента или любые два различных элемента — от этого зависит структура циклов.
  • Что вывести: обычно два числа — количество подходящих пар и максимум (или минимум) какой-то величины по этим парам.

📂Чтение данных из файла

Все числа из файла удобно сразу загрузить в список целых чисел — дальше работа идёт только с ним.

📐 Шаблон чтения последовательности:

nums = list(map(int, open('17.1.txt').readlines()))

Что происходит в этой строке, справа налево:

  • open('17.1.txt') — открывает файл;
  • .readlines() — читает все строки в список строк (у каждой на конце \n);
  • map(int, ...) — применяет int() к каждой строке;
  • list(...) — превращает результат в список чисел.
✅ Полезно знать: функция int() сама игнорирует пробелы и символы перевода строки \n, поэтому дополнительно очищать строки через strip() не нужно.

🔹 Альтернативная запись через списковое включение

nums = [int(x) for x in open('17.2.txt')]

Результат тот же самый — выбирайте вариант, который вам понятнее.

👯Перебор соседних пар

Если парой называются два идущих подряд элемента, достаточно одного цикла по индексам. На каждой итерации смотрим на элементы nums[i] и nums[i + 1].

Задача:

Файл содержит последовательность целых чисел. Назовём парой два идущих подряд элемента последовательности. Определите количество таких пар, в которых запись ровно одного элемента заканчивается цифрой 6, а сумма квадратов элементов пары меньше, чем квадрат наименьшего из элементов последовательности, запись которых заканчивается цифрой 6. В ответе запишите количество пар и максимальную сумму квадратов элементов этих пар.

Фрагмент файла 17.1.txt:

5196
-2074
-1943
3612
4303
-9995
2257
9386
-7653
-235
436
9738
983
💡 Подсказка: Сначала отдельным проходом найдите наименьший элемент, оканчивающийся на 6, — он нужен в условии проверки каждой пары.

Решение:

💡 Полный код решения:
nums = list(map(int, open('17.1.txt').readlines()))

# Проход 1: ищем наименьший элемент, оканчивающийся на 6
min_num = 0
for num in nums:
    if abs(num) % 10 == 6:
        min_num = min(min_num, num)

# Проход 2: перебираем соседние пары
count = 0
m = 0
for i in range(len(nums) - 1):
    if ((abs(nums[i]) % 10 == 6) != (abs(nums[i + 1]) % 10 == 6)) and (nums[i] ** 2 + nums[i + 1] ** 2 < min_num ** 2):
        count += 1
        m = max(m, nums[i] ** 2 + nums[i + 1] ** 2)
print(count, m)  # Ответ: 720 99266105

🔑 Ключевые моменты решения

  • Два прохода по данным: сначала ищем значение, участвующее в условии (наименьший элемент на 6), затем — сами пары.
  • Границы цикла: range(len(nums) - 1), чтобы nums[i + 1] не вышел за пределы списка.
  • Накопление ответа: счётчик count увеличиваем на 1, а максимум обновляем через m = max(m, ...).
⚠️ Важно: последнюю цифру числа проверяйте через abs(num) % 10. В Python остаток от деления отрицательного числа неотрицателен: -16 % 10 == 4, поэтому без abs() число −16 «не заканчивается» на 6.
⚠️ Важно: стартовое значение min_num = 0 корректно, только если в файле есть отрицательные числа, оканчивающиеся на 6 (минимум будет найден среди них). Если числа могут быть только положительными, инициализируйте min_num = float('inf') или используйте приём из главы «Минимум по условию».

🔽Поиск минимума по условию

В заданиях 17 постоянно требуется найти минимальный или максимальный элемент, удовлетворяющий условию (оканчивается на 6, делится на 3 и т.п.). Есть два компактных способа сделать это без ручного цикла.

🛠️ Способ 1: генератор внутри min() / max()

💡 Минимум среди элементов, оканчивающихся на 6:
min_num = min(x for x in nums if abs(x) % 10 == 6)
✅ Преимущество: самый надёжный способ — не нужно думать о начальном значении, в выборку попадают только подходящие элементы.

🛠️ Способ 2: параметр key у min() / max()

Функциям min() и max() можно передать key — функцию, по значению которой идёт сравнение. «Отсекаем» лишние элементы, назначая им заведомо проигрышный ключ:

💡 Тот же поиск через key=lambda:
min_num = min(nums, key=lambda x: x if abs(x) % 10 == 6 else float('inf'))

Логика: если элемент оканчивается на 6, его ключ — само число; иначе — float('inf') (бесконечность), и такой элемент никогда не выиграет сравнение на минимум.

⚠️ Ограничение: для min() «отсекающий» ключ — это float('inf'), для max() — float('-inf'). Если перепутать, получите неверный ответ.
Способ Начальное значение Риск ошибки Рекомендация
Ручной цикл Нужно выбрать самому Неверный старт (0, max и т.п.) Когда условие сложное
min(x for x in ... if ...) Не требуется Минимальный ✅ Основной вариант
key=lambda Не требуется Перепутанный «отсекающий» ключ Короткая запись в одну строку

⚡Исключающее ИЛИ (XOR) через !=

Условие «ровно один из двух элементов обладает свойством» (например, запись ровно одного элемента пары заканчивается цифрой 6) — это логическая операция исключающее ИЛИ (XOR):

Первый элемент оканчивается на 6 Второй элемент оканчивается на 6 Ровно один (XOR)
нет (0)нет (0)0
нет (0)да (1)1
да (1)нет (0)1
да (1)да (1)0

Из таблицы видно: XOR истинен, когда значения различны. Поэтому в Python исключающее ИЛИ двух булевых значений записывается обычным сравнением !=:

📐 Приём: замена длинного условия на !=

# Длинная запись: «первый оканчивается на 6, а второй нет — или наоборот»
(abs(nums[i]) % 10 == 6 and abs(nums[i + 1]) % 10 != 6) or (abs(nums[i]) % 10 != 6 and abs(nums[i + 1]) % 10 == 6)

# Короткая запись — то же самое через исключающее ИЛИ
(abs(nums[i]) % 10 == 6) != (abs(nums[i + 1]) % 10 == 6)
✅ Почему работает: оба выражения в скобках имеют тип bool. Оператор != вернёт True ровно тогда, когда одно из них True, а другое — False, то есть когда условие выполняется ровно для одного элемента пары.
⚠️ Важно: приём работает только для условия «ровно один из двух». Для «оба» используйте and, для «хотя бы один» — or, для троек элементов — подсчёт, например (усл1) + (усл2) + (усл3) == 1 (True считается за 1, False — за 0).

🔁Перебор любых двух элементов

Если под парой понимаются два различных элемента последовательности и порядок в паре не важен, нужен двойной цикл. Чтобы не рассматривать одну и ту же пару дважды и не брать элемент «в пару с самим собой», внутренний цикл начинается с i + 1.

Задача:

В файле содержится последовательность из 10 000 целых положительных чисел. Каждое число не превышает 10 000. Определите количество пар элементов, для которых произведение делится без остатка на 10, и максимальную из сумм элементов таких пар. Под парой подразумеваются два различных элемента последовательности, порядок элементов в паре не важен.

Фрагмент файла 17.2.txt:

5500
6971
3572
7600
2822
5687
9741
8623
7954
1029
9913
380
7965
3679
2626
3699
7972

Решение:

💡 Двойной цикл по всем парам:
nums = list(map(int, open('17.2.txt').readlines()))

count = 0
m = -20001  # стартовое значение меньше любой возможной суммы пары (максимум 10000 + 9999)
for i in range(len(nums)):
    for j in range(i + 1, len(nums)):
        if (nums[i] * nums[j]) % 10 == 0:
            count += 1
            if nums[i] + nums[j] > m:
                m = nums[i] + nums[j]
print(count, m)  # Ответ: 13510315 19999
✅ Почему j начинается с i + 1: каждая пара рассматривается ровно один раз, элемент не образует пару сам с собой, а пары (a, b) и (b, a) не дублируются — именно это и требует условие «порядок не важен».
⚠️ Важно: не называйте переменную max или min — так перекрываются встроенные функции Python, и последующий вызов max(...) сломается. Используйте имена вроде m, max_sum, ans.
⚠️ Производительность: двойной цикл — это O(n²). Для 10 000 чисел получится около 50 млн пар — Python справится за десятки секунд. Если файл заметно больше или программа не успевает, перепишите условие через подсчёт по группам (например, произведение делится на 10, если один из множителей делится на 10, или один чётный, а другой делится на 5).

🎓Заключение

Задание 17 — это всегда чтение файла в список чисел и перебор пар по шаблону.


Помните:

  • list(map(int, open(...).readlines())) — универсальное чтение файла
  • Соседние пары: один цикл до len(nums) - 1
  • Любые два элемента: двойной цикл, внутренний — с i + 1
  • Последняя цифра отрицательного числа — только через abs()
  • «Ровно один из двух» — это != (исключающее ИЛИ)
  • Минимум по условию: min(x for x in nums if ...)
